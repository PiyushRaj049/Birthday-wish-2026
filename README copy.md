# Navya's Birthday Website
Open `index.html` in a browser (double-click). Tap once anywhere to start the music.

- **Photos:** drop images into `images/solo`, `images/birthday-wish`, `images/memories`, then edit the `CFG` lists at the top of `script.js` (paths + captions).
- **Sound:** all music and effects are synthesised in the browser (Web Audio), so no audio files are required. `audio/` is kept for your own files if you later want to wire in real MP3s.
- **Text:** edit `index.html`.
